# TASK0052 — 赔率市场历史文件的赛前存在性复核

**日期：**2026-11-08；**对象：**EV-Lab竞彩足球；**输入：**TASK0051原175场相同比赛市场比较（固定源SHA）。

## 研究目标

此前175场市场概率比Poisson评分更好，但市场CSV是在赛后获得，缺乏独立的同期时间戳。检验同一提供方是否存在**早于比赛开球**的历史公开档案，并审计内容是否与后来的CSV一致。不是重新挑样本优化ROI。

## 事前研究纪律

1. 只读引用固定GitHub仓库提交`a2d6290bd36029b82a36bd749417c0e27222b8e7`所披露的TipsAudit原始档案；固定清单与12个原始文件的SHA256；不把原始数据二次发布到Git。
2. **只有文件生成时刻严格早于比赛开球且该比赛ID已出现在档案中**，才允许作为提供方赛前可见性候选；第一份赛前记录为准，不能挑较晚但内容更接近CSV的记录。
3. 对照原2026-11-03 CSV的固定`record_hash`；对记录缺失、哈希变化、球队身份变化、无赛前文件分别计数。
4. 冻结原TASK0051逐场评分记录（175条）；**只对符合严格档案规则的子样本**重算同场市场/Poisson分数，并报告按UTC日期重抽样误差区间。
5. 数据仅公开提供方的档案，`generated_at`为**提供方自声明时间**；不能替代验证OpenTimestamps的Bitcoin见证，更不能把一个记录哈希直接当作全部三项盘口均在当时可执行的独立证明。
6. 跨时点报价、封存原预测和Git锚必须分别举证。严格区分**媒体档案存在**与**独立市场PIT/CLV/EV**。

## 阶段验收

* **LIMITED ACCEPT：**12份SHA核验、全部175场不遗漏分类、源哈希/时间戳差异正确隔离、真实同场敏感性评分、两次SHA一致、对抗性测试、仓库报告/QA。
* **NO-GO：**不能把新的筛选结果用作真实可执行市场优势；未检查区块链OTS证明，且档案没有完整三向赔率、模型本身也非当时Git冻结的真实前向预测。
* Windows前向任务实际运行健康作为独立问题记录，不因数据研究成功而提升为生产可用。
