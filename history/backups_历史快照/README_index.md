## 四、说明

### 与主包的关系
- 主包（上一级目录的 `01_`~`19_`）覆盖 `/workspace` **当前状态**，**不含 `backups/`**
- 本目录是**补充**：`backups/` 的历史快照，用于追溯数据演进
- 两者**合起来 = `/workspace` 全量**（928 + 122 = 1050 文件）

### 为什么单独分卷
- `backups/` 原始 778MB，占 `/workspace` 总量约 70%
- 与 `data/` 高度重复（同一批文件的旧副本）
- 故与主包分离，需要时单独取用

### 边界
- 打包为**纯只读压缩**，未移动/删除/修改任何源文件
- 未触碰 `data/`、`scripts/`、`results/`
- **未**上传任何内容到 GitHub
