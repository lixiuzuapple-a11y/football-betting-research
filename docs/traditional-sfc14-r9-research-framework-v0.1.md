# EV-Lab｜中国传统足彩14场与任选9场研究框架 v0.1

- 状态：**研究框架草案 / DESIGN ONLY / 未开启实盘或自动开发**
- 日期：2026-11-02；归属：EV-Lab 的**独立支线**，不改变竞彩足球主线（TASK0043—0048）的模型、排程、验收或资金纪律。
- 首要目标：检验能否使用**停售前可获得的信息**，在中国传统足彩14场胜负彩（SFC14）、任选9场（R9）中识别收益与风险不对称的期次/组合，并在真实历史滚动及未来前向结算中证明增量价值。
- 默认结论：**正EV尚未证明**。追求可证伪研究，不承诺盈利，不执行真实投注。

## 1. 研究问题与统一定义

传统足彩是奖金共享型市场，不等同于竞彩固定赔率。研究不仅要估计比赛赛果，还要估计彩民对组合的选择和奖池分配。

三角结构：
- **P：比赛结果联合概率**。先使用同一时点的国际欧赔/亚盘去水市场概率作为基准，复用EV-Lab已有Elo/Poisson作独立比较。P是估计值，跨场独立只作为需检验的基线。
- **Q：全国有效投注行的联合分布**。SFC14为完整14场结果组合；R9还包括14选9的**选场子集分布**及其条件选号组合。竞彩SP残差、网络支持率和国外披露比例均只是可能的代理变量，不等于中国真实Q。
- **W：官方奖金与税后结算函数**。包括当期销量、可分配金额、往期滚存、调节基金转入、奖金封顶、取整、特殊派奖、各奖级中奖注数、我方新增投注对销量和中奖注数的稀释，以及按同人同期同游戏汇总的个税。

对于某一期 t、待评价的票组组合 C，核心是**完整收益分布**而不只是命中率：

`EV_t(C)=E_{P_t,Q_t,W_t}[TaxAfterPayout(C,ω,Ω_Q,S_t,rule_t)]-Cost(C)`

其中结果向量 ω 的概率、其他参与者的注数分布 Ω_Q、实际销售额及奖池均可能未知。**不得把P/M的比值、预测平均中奖人数代入分母，或者模拟最优组合的历史收益直接称为已证实正EV。**

研究的三个可独立证伪的总命题：
1. **A 概率命题**：同一期停售前欧亚盘是否提供可校准、可追溯的赛果概率？自有模型是否有增量？
2. **B 行为命题**：公众选号与市场概率是否存在可预测偏差？竞彩SP、媒体/投票、球队知名度是否解释这种偏差？
3. **C 奖金命题**：奖金规则、滚存与公众组合相关性是否造成可识别且经税后、风险和自我稀释校正后仍成立的收益差异？

## 2. 两玩法必须分别建模

| 维度 | SFC14 | R9 |
|---|---|---|
| 每注构成 | 同一期固定14场，各选1X2结果 | 从14场**选9场子集**，每场各选1X2结果 |
| 单注成本 | 2元 | 2元 |
| 奖级 | 14中14、13中14，两个浮动奖级 | 9中9，一个浮动奖级 |
| 样本空间 | 3^14=4,782,969条单式 | C(14,9)×3^9=39,405,366条单式（2,002子集） |
| Q建模核心 | 14场的**联合**组合分布，不可仅用14个单场边际相乘 | 子集分布Q(S)＋给定子集的结果组合分布Q(y_S∣S)，含跨场相关 |
| W建模核心 | 一等奖/二等奖、滚存/封顶分开结算 | 共同奖池、不同子集的获奖注数同池分配 |

R9的单场入选率`α_i=∑_{S∋i}Q(S)`，以及条件选号比例，是**必要但不充分**的观测摘要；不能据此恢复2,002个子集的联合分布，更不能断言“低入选率冷门必然无价值”。任何复式/胆拖/倍投注统一展开为**单式投注行及数量**，既记录票面也记录展开成本。

## 3. 研究架构：六层，但暂时只建设证据

**L0 规则与可用时间控制（确定性程序）**  
版本化核验当期官方期号、14场比赛、停售时刻、跨日/改期、取消赛果、游戏有效规则及税法生效日。使用两种时间：事件发生/赔率对应时点和**当时可获得/采集时点**；所有特征必须在整期停售前可得，不得使用各场分别的后续收盘赔率。身份不确定则隔离，不猜队名。

**L1 原始数据账本（确定性程序）**  
官方历史期次、赛程、销量、奖池、中奖注数与单注奖金；国内公开赛前竞彩SP及投票率（若可证实），国际欧亚盘的原始报价/交易时点/来源与采集时点；历史比分。原始响应保留原字节、SHA、URL、获取时间、许可与缺失原因；第三方公告与官方交叉核验，冲突不进正式样本。**禁止用事后补齐的赔率伪装成停售前数据。**

**L2 双轨建模（统计为主，AI辅助）**  
轨A/P：简单去水欧赔基线 → 欧亚盘市场组合与校准 → EV-Lab现有Elo/Poisson增量。比较同场同时间Log Loss、Brier与可靠性，而非只比胜负命中率。  
轨B/Q：独立市场赔率与竞彩SP在控制基本返奖/赔率段/时间差后的定价残差；公众支持率、热门/平局/豪门、选场子集、组合相关性及过度离散的中奖注数模型。研究**无Q时奖金能预测到什么程度**；允许Q不可识别并在此支线止步。  
在瑞典Stryktipset与西班牙La Quiniela等披露较多公众比例的市场做**方法验证**：真实单场比例 → 代理比例 → 中国可获得的有限信息，按时间留出检验信息退化；不预设保留40%之类门槛、不把国外参数直接移植中国。

**L3 W与反事实结算（确定性程序，独立QA）**  
逐期复算官方销售/奖池/奖级/中奖金额，包含14场二等奖、任9一奖、滚存、封顶、取整、派奖、特殊计奖和规则版本。**重放历史公告**与**假设新增我方票组的反事实结算**是两种不同模式，必须严格分开：后者将我方新增销量/中奖注数计入相应奖池和各奖级分母，处理官方零中奖和相应结转；按同人同期同游戏奖金合计适用2024年9月1日起的税务口径。历史规则变更单独记录。不能一概“公布单注奖金×中奖票数”。

**L4 EV与组合研究（确定性优化，只有过闸后开始）**  
先评估期次是否值得研究，再比较同预算下的SFC14/R9单式与有限组合；对P/Q/W的合理误差做情景扰动，考核税后利润分布、破产尾部、奖池自稀释和是否高度依赖单个大额开奖。不以“剔除大热”“每期几场冷门”作先验规则。对3^14与C(14,9)×3^9使用精确算法/搜索或有误差界的抽样；不把蒙特卡洛输出当作真实市场证据。Kelly/CVaR仅是损失约束工具，不能创造正EV。

**L5 时间冻结、独立验收与研究发布**  
每一期停售前冻结输入哈希、研究期次、可用时间、模型版本、候选票组、下注模拟成本和`PASS/NO-GO`；赛后自动抓官方结果和真实公告，独立程序复核中奖判定、奖金和税。GitHub记录方案/提交/报告/SHA，原始资料另存、保留事故及遗漏期次。AI不得修改已冻结选择；不做自动下单。

## 4. 20个探索问题，合并为5组研究主题

| 主题 | 覆盖的方向（属于假设池，不是20个开发任务） |
|---|---|
| **规则/奖池** | 官方派奖规则逐期复算、滚存/特别派奖、500万封顶与税务断点、销量与参与行为 |
| **概率P** | 多家欧赔去水、亚盘一致性、Elo/Poisson增量、整期停售前的盘口变化 |
| **公众Q** | 竞彩残差、热门/平局/冷门偏好、球队声望/媒体、整张票的选择相关性、任9入选率/子集分布 |
| **奖金W** | 中奖注数的分布预测、期次奖金预测、14场二等奖贡献、零中奖和自我稀释 |
| **方法与验证** | 任9选场、低成本组合搜索/重叠覆盖、稳健EV与尾部风险、固定规则真实历史结算、LLM信息增量 |

### 特别保留的高价值子假设

- **H1**：只看国际市场概率与当期公开奖池，是否已能区分高低奖金期次？
- **H2**：竞彩SP相对国际价格的**残差**，是否能在扣除基准定价差异后预测可独立观察的大众支持率或奖金分布？
- **H3**：在国外可观测真实公众选择比例的市场，单场独立Q基线会产生多大的中奖注数偏差？完整联合Q的额外可预测信息有多少？
- **H4**：任9的“选哪9场”相对“在既定9场中选什么”各自贡献多少？
- **H5**：滚存/派奖/14场二等奖是否独立带来期次选择价值？
- **H6**：严谨停售前数据＋奖金分布能否在未见期次中**税后**跑赢相同预算的简单概率基线？若不能，组合优化不得提升为“正EV策略”。

## 5. 实验顺序：三条线并行，避免互相等待

| 工作线 | 第一阶段最小成果 | 失败也应报告的结果 |
|---|---|---|
| **A 中国真实结算** | 抽取跨多年度且含不同规则期的代表性期次；逐期验证比赛/销量/中奖注数/各奖级和奖金；建立含缺失率的可复核数据字典与结算规则说明 | 官方公告不足、零中奖或特殊派奖无法复算；逐期明示差异，不掩盖 |
| **B P与赔率时间证据** | 核实14场身份映射＋同一期停售前能获得的欧赔/亚盘/竞彩SP覆盖率，形成真实可用样本账本 | 历史报价无法证明停售前可得，则只用于探索，不用于正式收益回测 |
| **C Q的可识别性** | 复现国外市场有公众比例时的中奖注数基线；检验隐藏Q后中国式代理信息的预测损失 | 价差不含增量、联合分布不可识别、迁移不成立，则不推断公众行为 |

三线有中间成果后，再独立提出**期次奖金预测试验**和**受控票组模拟结算试验**；二者的训练/验证时间必须在输出前冻结。主线足球EV-Lab照常运行，数据和代码尽可能复用，研究报告保持独立。

## 6. 测试、指标、准入与止损

- **样本单位**：以彩票**期次**为独立外层单位，比较两玩法时报告共享赛事相关性；不得用“14×期数”冒充独立观察量。
- **数据质量**：期号连续性、变更/延期、停售时点、赛果身份、原始SHA、官方奖金复算、历史规则一致性。先给出真实可用样本数量与选择偏差。
- **概率**：同场对比Log Loss、Brier、校准；固定基线和时间区间，避免看结果选去水方法。
- **公众/奖金**：先验基线与样本外增量；对数中奖注数、零中奖概率、分位数与分布校准、奖金误差；禁止只报告相关系数。
- **策略**：逐期固定纸面预算和`PASS`权利，所有失败、未中奖、缺价期次保留；报告**税后ROI、总成本、中奖期数、利润贡献集中度、最大回撤、尾部损失与不确定区间**。奖金高低预测准确不等于正EV。
- **基线**：全市场最高概率、简单欧赔去水、随机同预算、固定热门/冷门数量、无竞彩残差、无AI、无奖金模型；按分阶段消融比较。
- **严禁人为阈值**：不先规定“Rank IC>0.25”“保留40%信息”“>300场就可信”等任意准入数。先做样本规模/功效与奖金重尾风险分析，再在测试期开始前预注册阈值、停止规则、主要指标和否定条件。
- **压力测试**：P/Q/W共同偏差、赔率滞后、奖金尾部、无中奖、一个大奖驱动全部盈利、比赛相关性、参与度突然变化、规则切换、我方投注稀释。
- **最低科学闸门**：数据不可溯源→NO-GO；奖金复算失败→不得计ROI；概率/公众代理无样本外增量→降级或停止该分支；声称正EV需在可信前向期次、税后且含成本及不确定性前提下再审。
- **安全边界**：仅模拟研究、不得自动出票；明确区分理论点估计EV、稳健EV、历史模拟ROI、真实前向成绩四种不同证据等级。

## 8. 阶段交付与明确停止点

**D0 研究框架（本文件）**：冻结研究边界、命题、数据需求及对比框架。**不代表数据、模型或收益已经通过验收。**

**D1 证据可行性**：数据源真实性/许可/时间可得性审计表；中国多期奖金规则复算报告；海外Q公开性实测；赔率PIT覆盖率报告。只有D1完成才决定真正建哪些软件。

**D2 三条线独立实验**：P基线＋市场偏差、Q结构/海外消融、W奖金复算及中奖人数分布；公开完整缺失和负结果，独立QA。

**D3 时间滚动模拟**：固定资金/票组/停售时间、税后自我稀释结算，对比简单基线并对所有期次出账；先探索、再预注册锁定试验期。

**D4 真实前向**：停售前冻结，赛后官方奖金独立验收；正EV、组合选择能力或投资价值的任何宣称都须待D4数据支持。

**D5 有条件工程化**：只有D3/D4确认稳定增量后，考虑受控组合优化器及研究看板；始终不包含自动交易接口。

### D1的首要实际阻塞

1. 历史原始**整期停售前**欧亚盘/竞彩SP报价能否取得并验证时点；
2. 官方奖金的历史版本、特殊派奖/零中奖/滚存是否可以**逐期精确复算**；
3. 国外公开Q究竟是出票截止前可得还是事后汇总，以及是否有足够逐期中奖注数做有效的外样本测试。

对其中任一缺口必须明确写**PENDING/REJECTED及理由**，不得为了推进系统而悄悄采用后验数据。
