## Gates (all require actual evidence)
A. WAKE: scheduler actually runs without user message; manual run separately marked.
B. READ: fresh main SHA, status and raw evidence, not chat recollection.
C. DECIDE: meaningful bounded next task, WAIT or BLOCKED without busywork.
D. EXECUTE: one real non-destructive validation or source audit.
E. QA: independently verify evidence, exits and honest scientific limitations.
F. PERSIST: append a deduplicated run record to pilot branch, never production main.
G. REPEAT: a second independent wake reads prior record and avoids duplication.

If only A-C work, label LIMITED; do not call the loop self-running. Seven runs cap, then explicit review.
