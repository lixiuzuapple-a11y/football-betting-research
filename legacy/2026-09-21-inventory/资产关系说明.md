## 6. 数据一致性风险提示

| 风险 | 说明 |
|---|---|
| **`hist_v2.csv` 的日期格式是 `%d/%m/%Y`**（如 `01/01/18`） | 与 `fb_match_index.csv` 的 `%Y-%m-%d` **不一致**，join 时是潜在陷阱 |
| **`e54_join.csv` 时间范围显示 `01/01/2024 ~ 31/12/2023`** | min/max 字面排序结果（字符串序），**不代表数据错误**，但说明该列日期格式为 `%d/%m/%Y` |
| **`e17_pairs.csv` / `e18_pairs_ou.csv` 时间范围 `2017-08-04 ~ 2026-05-24`** | 跨度 9 年，需确认是否与声明的样本期一致 |
| **`sporttery_odds.csv` 时间范围仅 `2026-09-03 ~ 2026-09-06`** | 表内 `snapshot_time` 列的最大值；但文件 274K 行 / 40.9MB —— 说明**大部分行落在 4 天窗口内的高频快照**，属正常 |
| **`hafu_hist.csv` / `hafu_hist_fitted.csv` 无时间列** | 无法做时序对齐，跨源 join 需谨慎 |
| **`data/e58_census_odds.csv` 时间范围仅 2016~2019** | 与 `fb_match_index.csv`（2016~2026）**不同**，说明 E58 普查样本限定在早期年份，**不能当作全期数据使用** |
