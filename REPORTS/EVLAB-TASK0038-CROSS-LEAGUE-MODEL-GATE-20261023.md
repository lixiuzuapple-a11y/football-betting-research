# EV-Lab TASK-0038｜跨联赛历史覆盖、共同尺度基线与中国竞彩真实同场比较

**审计日期：2026-10-23。阶段决定：历史来源与受控比较流程研究 ACCEPT；固定参数跨联赛模型优于市场的主张 NO-GO；六场亚冠精英因共同尺度无证据 NO-GO。**

## 一、验证问题与已冻结输入

TASK-0037 已通过122/169场严格跨源身份关联，其中本阶段独立验证35场杯赛身份（欧冠15、欧罗巴10、欧协联2、亚冠精英6、解放者杯2）及35/35官方赛果和ESPN赛果一致；33场在历史采集中存在严格开赛前 HAD 竞彩去水概率。本阶段**不重新建立身份，也不以10月结果筛选球队别名或模型**。

历史来源是 TASK-0036 下载并校验原始 SHA256 的 [HuggingFace eatpizzanot/soccer-dataset](https://huggingface.co/datasets/eatpizzanot/soccer-dataset)，发布者最后修改时间 **2026-07-05T01:23:18Z**。历史样本严格截止2026-07-05 00:00:00（不包含），从2025-07-01开始；比赛日期、双方稳定 ID 和最终进球用于生成模型，**2026年10月的杯赛比分和任何竞彩赔率完全不参与训练**。原始第三方数据留 E 盘而不写GitHub；发布者CC-BY-4.0声明尚不能独立证明API-Football等上游商业再分发权利。

## 二、证明跨联赛强度尺度，而非将联赛单独参数硬拼

实际固定历史数据内，2025-07-01至2026-07-05前含欧冠 **281**、欧罗巴 **271**、欧协联 **409**、解放者杯 **155** 场已完赛记录。这些赛事在国内联赛之间提供球队间的真实比赛边，允许测试**共同强度图连通性**，但不自动证明概率校准合格。

通过人工核验的35场杯赛、70个唯一 ESPN 球队名称，对应到HF球队表的70个明确球队 ID 和原始名称（在代码 tools/task0038_teams.py 固化，运行时逐ID/名称二次校验）。特别拒绝把阿森纳另一同名俱乐部、罗马同名球队、帕尔梅拉斯的另一个 ID 或国际米兰与巴西国际队合并。测试真实训练历史的图结构：

- **35/35场**，双方都存在至少5场2025/26已知进球历史。
- **29/35场**，双方经过实际联赛/跨联赛杯赛连通到同一历史比赛图组件，其中欧洲杯赛27场，解放者杯2场。
- **6/35场亚冠精英**，尽管各自有历史比赛，但双方不在共同球队强度图中；**明确 NO-GO，不推断可横向比较的球队强度，不人为指定国家联赛强弱系数**。
- 29场有共同强度尺度的比赛中有**27场**同时具备早已冻结的赛前体彩HAD去水概率（欧冠14、欧罗巴9、欧协联2、解放者杯2），另外2场缺严格赔率而PASS。

### 输入去重的重要质量门槛

历史原始训练区间有 **54,621** 条已完赛记录，**53,705** 个唯一（UTC开球、主队ID、客队ID）键；其余 **916** 是跨来源的重复行；**所有重复键比分冲突为零**。按最小原始id保留唯一记录，并按开赛时间顺序处理。相同开球时刻的多场比赛先同时计算基于时间点前的概率，再统一更新评级，不允许同一时间点比赛使用其他已结束结果。所有样本均严格早于2026-10测试场次。

## 三、预先固定参数的统一 Elo / Davidson 三分类基线

调用新代码 tools/task0038_common_elo_model_gate.py，统一训练2025/26全联赛历史（含欧战、解放者杯）而非各联赛单独拟合再直接比较。所有球队初始 Elo=**1500**，逐场 K=**20**，主场增量=**50 Elo**，Davidson draw weight=**0.7**；这些是**本阶段预先固定、不用27场竞彩结局/赔率寻优**的可检验参考参数，不是声称统计最优的模型。进球结果转为1/0.5/0用于Elo更新。每场1X2概率只由两队历史 Elo 产生。只有同一历史比赛图联通、双方历史≥5、且有冻结严格HAD时才参与配对评分。

| 同场指标 | 跨联赛固定 Elo（独立） | 竞彩严格赛前去水市场 |
|---|---:|---:|
| 可比较比赛 | 27 | 27 |
| 胜平负准确率 | 40.74% | **62.96%** |
| 三分类 Log Loss（↓） | 1.071761 | **0.866541** |
| 三分类 Brier总和（↓） | 0.653252 | **0.496784** |
| RPS（↓） | 0.266372 | **0.197125** |

同场 Log Loss 配对差（独立减市场） **+0.205219**，方向显著不利于独立模型。按实际开球 UTC 日期分4个簇，重复4000次重抽样得到名义95%区间 **[+0.081069,+0.302440]**。**注意：只有4个日期簇，本数值绝不用于声称严格统计显著性或长期泛化能力；部分比赛共同日期强相关，此项只是探索性效应大小诊断。**

不要把这27场与TASK-0034的34场直接混合制造一个“61场有胜率”的成绩。两者历史来源、模型基线、赛事分布、评估问题不同，而且新模型的27场是依据可验证数据可得性而选择的回顾性样本，有选择偏差。

### 赔率污染的原版计算反例

独立保留原始27场预测概率；随后在冻结评分表副本中，**把所有竞彩概率改成 [0.8,0.1,0.1]**，从头重跑全部53,705场历史训练，重新对照同一27场。27/27独立三分类概率向量完全不变，独立模型 Log Loss 始终 **1.071761**；只改变市场端对照。反例输入和验收输出均留E盘，非实际投注结果。

## 四、分项结论与下一步决议

| 研究目标 | 结果 | 验收 |
|---|---|---|
| 35场新杯赛有否足够的历史进球？ | 双方历史各≥5：35/35；跨联赛共同尺度通过：29/35 | **部分ACCEPT** |
| 欧冠、欧罗巴等独立跨联赛概率能否跑出来？ | 统一历史图与固定 Elo/Davidson 可以得到27场有同场市场价的概率，但模型是否充分校准尚未经更大独立窗口证明 | **研究型ACCEPT，不批准生产** |
| 独立模型是否超越竞彩去水市场？ | 27场 Log Loss、Brier、RPS和准确率全部逊于市场 | **明确NO-GO** |
| 亚冠精英能否像欧战那样比较？ | 历史球队图仍分离，缺真正跨联赛共同赛事训练证据 | **NO-GO** |
| 可以开始自动交易/声称正EV吗？ | 无可靠正EV或长期前向证明，数据源授权及成交报价也未核验 | **NO-GO** |
