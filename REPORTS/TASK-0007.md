## 1. Executive result

The five-day prospective data contain many observations where the official Sporttery HAD quote remained unchanged and provider-declared executable after a same-variant BetExplorer `reference_proxy` change.

However, **D01-B as the intended clean lead-lag mechanism is not demonstrated**.

The decisive source-quality finding is:

> **Every one of the 580 matched reference-change rows occurred inside a mass synchronized batch of more than 20 changed BetExplorer events. There were zero matched changes in the pre-registered strongest `batch=1` stratum and zero in the `batch<=5` sensitivity stratum.**

Therefore the observed intersections cannot be cleanly interpreted as individual sharp-market moves leading a stale Sporttery quote.

Economic attribution is weaker still:

- 49 primary-candidate rows, across 7 fixtures, had at least one outcome with current `proxy_implied_ev > 0`.
- Across those rows there were 50 positive outcome instances.
- **48/50 were already proxy-positive before the reference move.**
- Only **2 outcome instances** crossed from pre-move proxy EV <= 0 to post-move proxy EV > 0.
- Those two occurred in mass batches of 47 and 98 changes, with honest reference-change time brackets of about 1.08 h and 4.21 h respectively.

Thus almost all apparent positive proxy EV is a pre-existing same-time residual (B01-like), not value created by the D01-B reference move.

Final research disposition for this task:

> **D01-B WITH CURRENT BETEXPLORER REFERENCE_PROXY = NOT VALIDATED / DOWNGRADE.**

No true-EV, profitability, BUY/PASS, or wagering claim is supported.

## 14. Interpretation against the preregistered gate

The raw primary definition produces 438 stale+executable intersections and 49 rows with current positive proxy-implied EV, so mechanically the analysis reaches preregistered gate C.

However, the preregistration explicitly requires judging whether the pattern is dominated by large synchronized reference batches, reversions, or a single/weak source phenomenon before treating it as meaningful.

It is dominated by large synchronized batches:

- 580/580 matched changes are >20-event batches;
- 438/438 primary candidates are >20-event batches;
- no matched evidence exists in batch=1 or batch<=5;
- 38.8% of primary rows revert on the very next same-variant observation;
- 48/50 post-move positive outcome instances were already proxy-positive before the move.

Therefore gate C yields **prospective reference-proxy candidates in a mechanical sense only**, not a credible D01-B signal.

## 15. Research conclusion

### What is established

- The collector can observe very fast Sporttery confirmations after a BetExplorer response.
- Sporttery HAD/provider-time can remain unchanged and executable for long periods.
- The five-day dataset contains many intersections of reference changes with those static Sporttery quotes.

### What is not established

- That BetExplorer changes in this dataset represent clean individual sharp-market information arrivals.
- That D01-B provides incremental economic value beyond pre-existing B01-like residuals.
- That any observed proxy-positive row is true positive EV.
- That D01-B should be used for live BUY/PASS decisions.

### Decision

> **D01-B with the current BetExplorer `reference_proxy` is downgraded / not validated.**

Do not launch live betting from this signal.

Do not spend another five days replicating the same source behavior merely to repair TASK-0006 sealing. A future D01-B revival should first obtain a better-behaved reference source — ideally a named, timestamped market/feed with materially clearer update semantics.

The stronger next research lead from this dataset is **B01 same-time residual revalidation**, because almost all positive post-move proxy-EV instances were already positive before the move. That is a separate question and requires its own preregistration.
