## 独立审计发现并纠正的错误

第一次使用 PowerShell `ConvertFrom-Json` 后又将已自动日期转换的字段交给 `DateTimeOffset.Parse`，错误地叠加了本机 UTC+8 偏移，误判所有 244 条价格更新已滞后约 8 小时，开球余量也少算 8 小时。随后**直接从原 JSON 字符串**用 Python 的时区感知 ISO8601 解析独立重算，才得到上文 0.12–1.34 分钟及 251–467 小时结果。已将先前错误结果作废，并留此说明；后续任何赔率时钟比较必须从原字符串按 UTC-aware 方式计算，不允许自动本地时区二次转换。

离线第二方法重新校验原始字节 SHA、18 唯一事件、法甲 sport key、20 家唯一博彩公司、18 个 Pinnacle 事件、244 条完整 1X2、全部报价 age≤15 分钟且无坏价；独立重算 PASS。TASK0061 原门禁回归 **16 passed**，全仓 `pytest` **592 passed**。
